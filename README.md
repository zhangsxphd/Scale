# MVT-485Pro 智能称重系统

本项目通过 Modbus RTU 读取 MVT-485Pro 称重变送器，并提供仅限本机访问的 Flask Web 控制台。支持实时重量、状态曲线、日常去皮、增益标定及受控参数配置。

## 安全边界

- 默认仅监听 `127.0.0.1:5050`，避免局域网内其他设备直接调用写寄存器接口。
- 标定前必须由界面明确确认；后端还会检查读数稳定和超载状态。
- 标定流程由后端约束：必须先完成空载零点，再按点 1 到点 4 顺序记录，且重量必须递增。
- 已记录的加载点可以重新记录；重录某一点会保留此前点位，并使其后的点位回到待标定状态。重做零点才会使全部加载点失效。
- 重复写入同一标定点会覆盖该点。读取或验证重量时不要点击标定按钮。
- 当前设备小数点位置为 2 时，主界面保留两位小数；显示位数跟随设备参数。
- 参数值会先校验范围，写入后回读确认；设备未确认时接口不会报告成功。
- “空载零点标定”使用功能码 16 向 `0x0016–0x0017` 写入非零 32 位值；日常临时去皮仍向 `0x0006` 写入 `1`，两者严格区分。
- 页面显示的是“本次标定会话进度”。它只保存在 Flask 进程内存中，重启程序或修改连接参数后会清空；`0/5` 不表示设备内部没有标定。

## 运行

要求 Python 3.9 或更高版本：

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

也可双击 macOS 的 `start.command`。浏览器访问 <http://127.0.0.1:5050>。

默认串口为 `/dev/cu.usbserial-10`。可通过环境变量覆盖：

```bash
SCALE_SERIAL_PORT=/dev/cu.usbserial-XX SCALE_BAUDRATE=38400 python3 app.py
```

其他变量：`SCALE_MODBUS_ADDR`、`SCALE_SERIAL_TIMEOUT`、`SCALE_HOST`、`SCALE_PORT`、`LOG_LEVEL`。只有在可信网络和具备访问控制时，才应将 `SCALE_HOST` 改为 `0.0.0.0`。

## 设备协议

本节以仓库内 `称重计说明书/协议说明书/MVT-485协议手册v0.002.pdf` 为协议定义依据。实际设备通信测试只用于验证实现，不用于猜测或扩展厂家未定义的寄存器。

串口默认参数为 `38400 8-N-1`，默认站号 `0x01`。手册确认的本项目使用寄存器如下（地址均为十六进制）：

| 地址 | 方向 | 定义 |
| --- | --- | --- |
| `0x0000–0x0001` | 读 | 实时重量，32 位有符号整数，高字在前 |
| `0x0002` | 读 | 状态字：bit0 稳定、bit1 超载、bit2 零位、bit3 负数 |
| `0x0006` | 写 | 日常去皮，写入非零值 |
| `0x0007` | 读/写 | 上电清零开关 |
| `0x0008` | 读/写 | 零点跟踪范围 |
| `0x0009` | 读/写 | 判稳范围 |
| `0x000A` | 读/写 | 清零范围 |
| `0x000C` | 读/写 | 稳态滤波 |
| `0x000D` | 读/写 | AD 采样率 |
| `0x0012` | 读/写 | 小数点位置 `dp` |
| `0x0013` | 读/写 | 最小分度值 |
| `0x0014–0x0015` | 读/写 | 最大量程原始值，32 位无符号数，高字在前 |
| `0x0016–0x0017` | **读** | 实时传感器信号，32 位有符号数，高字在前 |
| `0x0016–0x0017` | **写** | 空载零点标定命令；功能码 16 写入任意非零 32 位值 |
| `0x001E–0x001F` | 写 | 加载点 1，32 位砝码重量原始值 |
| `0x0020–0x0021` | 写 | 加载点 2，32 位砝码重量原始值 |
| `0x0022–0x0023` | 写 | 加载点 3，32 位砝码重量原始值 |
| `0x0024–0x0025` | 写 | 加载点 4，32 位砝码重量原始值 |

多点标定必须按砝码重量从小到大使用不同点位。点 1 为十进制地址 30（`0x001E`），点 2/3/4 依次为 `0x0020/0x0022/0x0024`。

写寄存器前应核对设备型号和协议版本。项目不会自动扫描或试写未知寄存器。

### 参数写入顺序

一次请求同时修改多个参数时，程序按固定顺序写入并逐项回读：普通 16 位参数 → 小数位 `dp` → 最大量程。最大量程原始值始终按目标小数位计算：`max_range_raw = round(max_range_g × 10^target_dp)`。这避免了同时提交 `dp` 和 `max_range_g` 时使用旧小数位换算。

### UNVERIFIED

- 厂家界面中的“多点标定”复选框是否对应可持久读写的独立寄存器，协议手册未定义。
- 加载点寄存器能否可靠读回并用于程序重启后恢复标定进度，尚未得到协议定义和实机验证。因此程序不会据此推断设备内部标定状态。
- 设备在完整量程内的精度、线性、重复性和长期漂移尚未经过计量验证；界面稳定标志不等同于计量合格。
- Web 界面的 `3000 g` 上限是本项目 3 kg 设备的安全约束，不是对所有 MVT-485Pro 型号的通用协议结论。

## API

- `GET /api/status`：实时重量和状态
- `GET /api/params`：读取设备参数
- `POST /api/params`：校验、写入并回读参数
- `POST /api/zero`：日常去皮
- `POST /api/calibrate`：增益标定，要求 `confirm: true`
- `GET /health`：服务存活检查，不访问串口
